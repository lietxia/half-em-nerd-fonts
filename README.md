# 0.5em Nerd Fonts

> 拉丁字符宽度正好是中文一半（0.5em）的 Nerd Font 字体清单。

em 是字身宽（全角），en 是 em 的一半（半角）。多数编程字体拉丁字宽约 0.6em，
下面这批实测为 **0.5em**——与全角中文混排时天然 2:1 对齐，Markdown 表格和代码注释不会错位。
全部为 Nerd Fonts 官方打补丁版本，开箱自带终端/编辑器图标，无需自己 patch；且均为静态字重。
想要 0.5em 可变字重，见文末说明。

## 想要 0.5em 的可变字体

Nerd Fonts 官方补丁包全部是静态字重。可行路线：

- **Iosevka / 系**：官网 customizer 构建 VF，再自行 `font-patcher` 打图标。
- **Inconsolata**：`Inconsolata-VF.ttf`（wght 轴），同样自行打图标。
- **Maple Mono**：`--width slim`（字宽 500 = 0.5em）+ `--nf-variable` 直接构建出 0.5em 可变 NF：
  [subframe7536/maple-font](https://github.com/subframe7536/maple-font)。这是唯一开箱能同时满足三项的方案。

## 数据来源

- 字宽：下载各字体 Regular 版，用 fontTools 实测 52 个 ASCII 字母/数字的 `advanceWidth / unitsPerEm`，确认全部等于 0.5。
